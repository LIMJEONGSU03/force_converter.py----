# 힘 단위 변환기

## 용도

Tkinter 데스크톱 프로그램으로, 입력한 힘을 뉴턴(N), 킬로뉴턴(kN), 킬로그램힘(kgf)으로 변환해 세 단위의 결과를 함께 보여줍니다. 입력 단위는 `N`, `kN`, `kgf` 중에서 선택할 수 있으며, 기본 선택은 `kN`입니다.

## 화면 조작

- **전체 화면** 버튼 또는 `F11` 키로 전체 화면과 창 모드를 전환합니다.
- 전체 화면에서 `Esc` 키를 누르면 창 모드로 돌아갑니다.
- **최소화** 버튼으로 프로그램 창을 작업 표시줄로 내릴 수 있습니다.

## 필요한 환경

- Python 3
- Tkinter를 사용할 수 있는 Python 설치

이 프로그램은 Python 표준 라이브러리의 `tkinter`만 사용합니다. Tkinter가 설치되어 있지 않다면 해당 Python 환경에 Tkinter를 추가해야 합니다.

## 실행 명령

터미널에서 프로그램 파일이 있는 폴더로 이동한 다음 실행합니다.

```bash
python "force_converter.py 계산기.py"
```

Windows에서는 Python Launcher를 사용해 실행할 수도 있습니다.

```powershell
py ".\force_converter.py 계산기.py"
```

## 입력 예시

### 정상 입력

입력값 `2.5`, 단위 `kN`을 선택하고 **변환**을 누르면 다음 결과가 표시됩니다.

```text
입력 값: 2.50 kN
결과: 2500.00 N
결과: 2.50 kN
결과: 254.93 kgf
```

### 오류 입력

`abc`처럼 숫자가 아닌 값, `0`, 또는 `-1`을 입력하면 다음 오류가 표시됩니다.

```text
잘못된 입력입니다. 양의 숫자를 입력하세요.
```

## 변환 기준

- `1 N = 1 N`
- `1 kN = 1,000 N`
- `1 kgf = 9.80665 N`

결과는 소수점 둘째 자리까지 표시됩니다.

## CSV 하중 분석 프로그램

`load_analyzer.py`는 같은 폴더의 `load_bad.csv`를 읽어 행별 응력과 최대값을 분석합니다. 입력 CSV에는 다음 열이 있어야 합니다.

| 열 이름 | 의미 | 단위 |
| --- | --- | --- |
| `time_s` | 측정 시간 | s |
| `force_N` | 하중 | N |

응력은 `stress_MPa = force_N / area_mm2`로 계산합니다. `N/mm2`는 `MPa`와 같으며, 단면적은 `load_analyzer.py`의 `area_mm2 = 100`에서 설정합니다. 기준응력은 `reference_stress_MPa = 6`이며, 이 값보다 큰 응력(`> 6 MPa`)의 데이터 개수를 출력합니다.

### 필요한 환경

- Python 3
- `matplotlib`

`csv`, `math`, `pathlib`는 Python 표준 라이브러리입니다. `matplotlib`이 없다면 분석에 사용할 Python 환경에 설치합니다.

```bash
python -m pip install matplotlib
```

### 실행 명령

프로그램 파일과 CSV가 있는 폴더에서 실행합니다.

```bash
python .\load_analyzer.py
```

Windows에서는 다음 명령도 사용할 수 있습니다.

```powershell
py .\load_analyzer.py
```

다른 입력 파일을 사용하려면 `load_analyzer.py`의 `csv_path` 파일명을 변경합니다.

### 출력

- 콘솔: 제외한 행 수, 유효 데이터 수, 최대 하중과 해당 시간, 최대 응력과 해당 시간, 기준응력 초과 데이터 수
- `load_result.csv`: 유효 데이터의 `time_s`, `force_N`, 계산된 `stress_MPa` 열
- `stress_plot.png`: 시간–응력 그래프. 최대 응력점은 빨간 점과 값으로 표시합니다.

결과 파일은 프로그램과 같은 폴더에 저장됩니다. 원본 입력 CSV는 수정하지 않습니다.

### Tkinter 그래프 화면

`load_analyzer_gui.py`를 실행하면 CSV를 직접 선택할 수 있는 하중 분석 창이 열립니다. 상단에서 CSV 파일을 선택하면 `time_s`와 `force_N` 값이 모두 유효한 행의 수를 표시합니다. 단면 종류를 선택하면 해당 단면에 필요한 치수 입력칸만 표시합니다. 모든 치수는 mm, 단면적은 mm²입니다.

#### CSV 형식

CSV 첫 행에는 다음 열 이름이 정확히 있어야 합니다. 열 순서는 바뀌어도 됩니다. 시간은 초(s), 하중은 뉴턴(N) 단위이며, 각 데이터 행에서 두 값 모두 유한한 숫자여야 유효 데이터로 포함됩니다.

| 열 이름 | 의미 | 단위 |
| --- | --- | --- |
| `time_s` | 측정 시간 | s |
| `force_N` | 하중 | N |

#### 단면 치수와 계산식

| 단면 종류 | 입력 치수 | 단면적 공식 | 유효 치수 조건 |
| --- | --- | --- | --- |
| 사각형 | 폭 `b`, 높이 `h` | `b × h` | `b > 0`, `h > 0` |
| 원형봉 | 지름 `d` | `πd² / 4` | `d > 0` |
| 원형관 | 외경 `D`, 내경 `d` | `π(D² − d²) / 4` | `D > d > 0` |
| 사각형관 | 외부 폭 `B`, 높이 `H`, 두께 `t` | `BH − (B − 2t)(H − 2t)` | 치수 양수, `2t < min(B, H)` |
| H형강 | 플랜지 폭 `B`, 전체 높이 `H`, 웨브 두께 `tw`, 플랜지 두께 `tf` | `2Btf + (H − 2tf)tw` | 치수 양수, `2tf < H`, `tw ≤ B` |

모든 치수 입력은 mm이며, 계산된 단면적은 mm²입니다.

#### 이상화 단면 가정

- 사각형관은 바깥 치수가 `B × H`인 직사각형에서, 각 벽의 두께가 일정한 동심 직사각형 구멍을 뺀 단면으로 취급합니다. 따라서 안쪽 치수는 `B − 2t`, `H − 2t`입니다.
- H형강은 위아래 플랜지의 폭과 두께가 같고 웨브가 중앙에 있는 대칭 단면으로 취급합니다. `H`는 전체 높이이며, 두 플랜지 사이의 웨브 높이는 `H − 2tf`입니다. 면적은 플랜지 두 개와 그 사이 웨브 면적의 합으로 계산합니다.
- 계산은 이 명목 치수에 따른 이상적인 단면적을 사용하며, 모서리 곡률·필렛·모따기·제조 공차·재료 변형은 반영하지 않습니다.

#### 분석 및 오류 처리

**분석**을 누르면 `stress_MPa = force_N / A`로 각 행의 응력을 계산합니다. N/mm²는 MPa와 같으므로 응력은 MPa로 표시합니다. 최대 응력과 해당 시간을 표시하고, 하단에 `Time (s)`–`Stress (MPa)` 그래프를 그리며 최대점은 빨간색으로 표시합니다. 치수나 단면 종류가 바뀌면 이전 결과와 그래프를 지우므로 다시 분석해야 합니다.

- CSV에 `time_s` 또는 `force_N` 열이 없거나 파일을 읽을 수 없으면 오류 창을 표시합니다. 파일 선택 창을 취소하면 현재 상태를 유지합니다.
- `time_s` 또는 `force_N`이 비어 있거나 숫자가 아니거나 유한하지 않은 행은 제외하며, 제외 행이 있으면 제외한 행 수를 경고 창에 표시합니다.
- 유효 데이터가 없으면 분석을 진행하지 않고 CSV 선택 안내를 표시합니다.
- 입력한 치수가 숫자가 아니거나 유한한 양수가 아니면 단면적 표시를 입력 확인 상태로 바꾸고, 분석 시 오류 창을 표시합니다.
- 원형관은 외경이 내경보다 커야 합니다. 사각형관은 두께의 두 배가 폭과 높이 각각보다 작아야 합니다. H형강은 플랜지 두께의 두 배가 전체 높이보다 작고, 웨브 두께가 플랜지 폭 이하이어야 합니다. 조건을 만족하지 않으면 분석 시 원인을 오류 창으로 알립니다.
- 계산된 단면적이 유한한 양수가 아니거나 응력이 유한하지 않으면 분석을 중단하고 오류 창을 표시합니다.

```powershell
py .\load_analyzer_gui.py
```

### 오류 처리

- 입력 CSV에 `time_s` 또는 `force_N` 열이 없으면 필요한 열을 알리는 오류로 분석을 중단합니다.
- 각 행의 `time_s`나 `force_N`이 비어 있거나 숫자가 아니면 원본 CSV의 행 번호와 문제값을 출력하고 해당 행을 분석에서 제외합니다. 제외 행은 한 번만 집계합니다.
- 유효하지 않은 행을 제외한 뒤 유효 데이터가 하나도 남지 않으면 안내를 출력하고 계산을 중단합니다. 이 경우 결과 CSV와 그래프는 새로 저장되지 않습니다.
